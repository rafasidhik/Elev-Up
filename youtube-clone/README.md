# YouTube Clone

A modern, responsive YouTube-inspired video browsing and streaming application built with React, Vite, and CSS3.

---

## 📌 Overview

**YouTube Clone** (ViewTube) is a video streaming and browsing interface designed to provide a YouTube experience. It features dynamic video search, category filtering, dedicated video player pages with actual video playback, channel subscriptions, like and watch-later management, watch history tracking, and dark/light theme switching with local storage persistence.

---

## ✨ Features

- 🎥 **Video Streaming Player:** Dedicated watch page with HTML5 video player, controls, playback error handling, and related video suggestions.
- 🔍 **Dynamic Video Search:** Instant real-time video search filtering by title, creator channel, or category without page reloads.
- 🏷️ **Category Filter Chips:** Horizontal scrollable category bar (Music, Gaming, Technology, Programming, Education, News, Entertainment) to quickly explore topics.
- 📈 **Trending Page:** Dedicated trending feed showcasing the most-watched videos sorted by view count.
- 🔔 **Subscriptions Feed:** Follow favorite creator channels with one-click subscribe/unsubscribe and view recent channel uploads.
- 🕒 **Watch History:** Tracks watched videos chronologically with one-click "Clear History" option.
- ⏰ **Watch Later:** Save videos for later viewing from cards or video pages with instant persistence.
- 👍 **Liked Videos:** Thumbs-up favorite videos, track likes, and access saved videos in a dedicated collection.
- 🎨 **Dark & Light Themes:** YouTube-inspired theme toggle between high-contrast Dark mode and clean Light mode.
- 📱 **Adaptive & Collapsible Sidebar:** Full navigation sidebar on desktop with compact collapse and touch-friendly mobile drawer overlay.
- 💾 **Local Storage Persistence:** Preserves theme preference, liked videos, subscriptions, watch later, and watch history across sessions.
- 📱 **Fully Responsive:** Layout tuned for desktop, tablet, and mobile screens with zero horizontal overflow.

---

## 🛠️ Tech Stack

- **React (v19):** Functional components, custom hooks, and state management
- **Vite:** High-performance frontend build tool and dev server
- **React Router DOM (v7):** Client-side routing and deep-linking navigation
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, and responsive design
- **HTML5:** Semantic markup, video player, and accessible ARIA attributes
- **Lucide React:** Modern, lightweight vector icons

## 🚀 Getting Started

### Prerequisites

A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.) and [Node.js](https://nodejs.org/) (v18 or newer).

### Installation

Clone the repository:

```bash
git clone https://github.com/rafasidhik/Elev-Up.git
cd Elev-Up/youtube-clone
```

### Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the displayed localhost URL (e.g., `http://localhost:5173`) in your web browser.
