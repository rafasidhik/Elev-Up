# Login & Registration Interface

A modern, responsive authentication interface featuring login and registration forms with robust client-side validation.

---

## 📌 Overview

**Login & Registration Interface** provides a clean, user-friendly authentication workflow. It includes dedicated Login and Sign Up pages with smooth navigation between them, paired with JavaScript validation to enforce valid emails, secure password complexity rules, and password matching before submission.

---

## ✨ Features

- 🔐 **Dual Form Workflow:** Separate Login (`index.html`) and Registration (`signup.html`) pages with mutual links.
- 👤 **Comprehensive Input Fields:** Name, email, password, and confirm password inputs.
- ⚠️ **Smart Client-Side Validation:**
  - Email format checks using regular expressions.
  - Strong password validation (8–16 characters, uppercase, lowercase, number, and special symbol).
  - Password confirmation matching on signup.
  - Inline error messages highlighting invalid inputs.
- 🎨 **Clean & Modern UI:** Centered card layout with sleek focus states, smooth transitions, and subtle shadows.
- 📱 **Fully Responsive:** Adapts seamlessly across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic forms and input types
- **CSS3:** Flexbox, form styling, transition effects, and responsive design
- **JavaScript (ES6):** Event-driven form handling, regex validation patterns, and DOM error rendering

## 🚀 Getting Started

### Prerequisites

A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Installation

Clone the repository:

```bash
git clone https://github.com/rafasidhik/Elev-Up.git
cd Elev-Up/login-registration
```

### Run Locally

Open `index.html` in any web browser.
