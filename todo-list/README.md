# React To-Do List

A modern, interactive, and responsive To-Do List application built with React, Vite, and CSS3.

---

## 📌 Overview

**React To-Do List** is a modern task management dashboard designed to help users organize daily goals efficiently. It features real-time overview statistics, an interactive task list with inline editing, dynamic status filters, delete confirmations, dark and light theme switching, and automatic local storage persistence.

---

## ✨ Features

- 📝 **Task Input Field:** Fast task entry supporting `Enter` key submission and empty input validation.
- 📋 **Interactive Task List:** Displays active and completed tasks with smooth transitions and relative timestamps.
- ➕ **Add Tasks:** Create tasks instantly with automatic whitespace trimming and autofocus.
- ✏️ **Inline Editing:** Edit task titles directly in place with dedicated Save and Cancel controls (`Enter` to save, `Esc` to cancel).
- 🗑️ **Delete with Confirmation:** Safe deletion workflow with an inline confirmation prompt to prevent accidental removals.
- 📊 **Real-Time Statistics:** Dynamic dashboard cards tracking Total Tasks, Active Tasks, and Completed Tasks, alongside an animated completion progress bar.
- 🔍 **Status Filter Tabs:** Filter tasks smoothly between **All**, **Active**, and **Completed** with live count badges.
- 🎨 **Dark & Light Themes:** One-click toggle between crisp Light mode and sleek Dark mode.
- 💬 **Action Feedback:** Lightweight toast notifications confirming additions, updates, completions, and deletions.
- 💾 **Local Storage Persistence:** Keeps your tasks and theme preference saved automatically across browser reloads.
- 📱 **Fully Responsive:** Modern card layout optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **React (v19):** Functional components, custom hooks, and dynamic state management
- **Vite:** High-performance frontend build tool and dev server
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, and responsive design
- **HTML5:** Semantic markup and accessible ARIA attributes
- **Lucide React:** Modern, lightweight vector icons

## 🚀 Getting Started

### Prerequisites

A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.) and [Node.js](https://nodejs.org/) (v18 or newer).

### Installation

Clone the repository:

```bash
git clone https://github.com/rafasidhik/Elev-Up.git
cd Elev-Up/todo-list
```

### Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the displayed localhost URL (e.g., `http://localhost:5173`) in your web browser.
