# Portraits - Search Engine & Photo Gallery

A clean, modern Pinterest-inspired photo gallery and search engine interface built with HTML5 and CSS3.

---

## 📌 Overview

**Portraits** is a responsive web interface designed to showcase photography with an integrated search experience. It features a hero search section, clean navigation, and a dynamic masonry-style image grid that adapts smoothly across all screen sizes.

---

## ✨ Features

- 🔍 **Search Interface:** Prominent search bar with search icon for querying photos, artists, and collections.
- 📸 **Branding & Navigation:** Modern navbar with logo, navigation links, and profile icon.
- 🖼️ **Masonry Gallery:** Pinterest-style layout displaying photos in an aesthetic grid.
- 🎨 **Interactive Hover Effects:** Smooth animations and zoom effects on gallery items.
- 📱 **Fully Responsive:** Optimized for mobile, tablet, laptop, and desktop displays.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic page structure
- **CSS3:** Flexbox, multi-column masonry layout, and media queries
- **Font Awesome:** Vector icons

---

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Installation

Clone the repository:

```bash
git clone https://github.com/rafasidhik/Elev-Up.git
cd Elev-Up/search-engine
```

### Run Locally

Simply open `index.html` in any web browser.
