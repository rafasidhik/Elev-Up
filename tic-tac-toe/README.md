# Tic Tac Toe

A clean, interactive, and responsive Tic-Tac-Toe web game built with HTML, CSS, and JavaScript.

---

## 📌 Overview

**Tic Tac Toe** is a classic browser-based game featuring a modern user interface. It supports both 2-Player (PvP) and Player vs Computer (AI) modes, complete with real-time turn tracking, winner and draw detection, and instant restart functionality.

---

## ✨ Features

- ❌ **Player Turns:** Alternating turns for Player X and Player O.
- 🤖 **Multiple Game Modes:** Choose between **Player vs Player** and **Player vs Computer**.
- 🏆 **Winner & Draw Detection:** Automatic evaluation of winning combinations and stalemate conditions.
- 🔄 **Restart Game:** One-click board reset at any point during gameplay.
- 🎨 **Modern Design:** Smooth hover animations, clean typography, and responsive layout.

---

## 🛠️ Tech Stack

- **HTML5:** Game structure and UI elements
- **CSS3:** Styling, grid layout, animations, and responsiveness
- **JavaScript (ES6):** Game logic, turn handling, AI moves, and win detection
