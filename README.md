## About

ElevUp by μLearn MCE is an intensive 10-day sprint diving into Web Development. Whether writing clean code, crafting intuitive interfaces, or securing networks, it is a hands-on learning experience guided by expert mentorship.

This repository documents my practical web development projects completed throughout the sprint, progressing from core HTML/CSS fundamentals to dynamic, API-driven web applications.

## Projects

| # | Project | Description | Tech Stack | Links |
|:---:|---|---|---|---|
| 01 | [Portraits - Search Engine](./search-engine) | Pinterest-inspired photo gallery and search interface featuring a responsive masonry grid and hover animations. | HTML5, CSS3, Font Awesome | [Live Demo](https://search-eng1ne.vercel.app/) |
| 02 | [Tic Tac Toe](./tic-tac-toe) | Classic interactive 3×3 game supporting Player vs Player and Player vs Computer (AI), turn tracking, winner/draw detection, and restart. | HTML5, CSS3, JavaScript | [Live Demo](https://t1c-t4c-toe.vercel.app/) |
| 03 | [Personal Budget Tracker](./budget-tracker) | Personal finance dashboard with real-time budget calculations, categorized transaction logging, and local storage persistence. | HTML5, CSS3, JavaScript | [Live Demo](https://budget-tr4cker.vercel.app/) |
| 04 | [Login & Registration](./login-registration) | Clean authentication interface featuring separate login and signup views with comprehensive regex and password validation. | HTML5, CSS3, JavaScript | [Live Demo](https://log1n-form.vercel.app/) |
| 05 | [Weather App](./weather-app) | Real-time global weather dashboard fetching current temperatures, humidity, and wind speeds via OpenWeatherMap API and serverless proxy. | HTML5, CSS3, JavaScript, OpenWeatherMap API, Vercel | [Live Demo](https://weather-4pp.vercel.app/) |
| 06 | [Movie Explorer](./movie-listing) | Responsive movie browsing application with OMDb API search, poster displays, IMDb ratings, and an interactive details modal. | HTML5, CSS3, JavaScript, OMDb API, Vercel | [Live Demo](https://movie-l1sting.vercel.app/) |
