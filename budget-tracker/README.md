# Personal Budget & Expense Tracker

A clean, responsive personal finance and budget tracker built using HTML, CSS, and JavaScript.

---

## 📌 Overview

**Personal Budget & Expense Tracker** helps users manage their personal finances with ease. Set a monthly budget, log categorized expenses, track current balance in real time, and retain all transaction records locally using browser storage.

---

## ✨ Features

- 💰 **Set Monthly Budget:** Input and update your total available budget.
- ➕ **Add Categorized Expenses:** Log expenses with custom descriptions and predefined categories (Housing, Food, Utilities, etc.).
- ➖ **Remove Transactions:** Delete individual expense items with instant balance recalculation.
- 💵 **Real-Time Dashboard:** View Total Budget, Total Expenses, and Remaining Balance metrics automatically.
- 💾 **Local Storage Persistence:** Keeps your budget and expense data saved across browser sessions.
- 📱 **Responsive Design:** Clean asymmetric split layout optimized for desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and form elements
- **CSS3:** Flexbox, CSS Grid, cards, custom color-coded status badges, and responsive design
- **JavaScript (ES6):** DOM manipulation, real-time math calculations, and LocalStorage API

## 🚀 Getting Started

### Prerequisites

A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Installation

Clone the repository:

```bash
git clone https://github.com/rafasidhik/Elev-Up.git
cd Elev-Up/budget-tracker
```

### Run Locally

Open `index.html` in your web browser.
