# Personal Portfolio Website

A clean, minimal, and responsive developer portfolio website built using HTML, CSS, and JavaScript.

---

## 📌 Overview

**Personal Portfolio Website** is a clean, minimal personal portfolio designed to showcase completed web development projects and technical capabilities. Featuring an editorial, typography-focused aesthetic, it highlights frontend projects with live demonstrations, visual previews, technical skill categorization, and direct contact channels.

---

## ✨ Features

- 🎨 **Minimal & Editorial Design:** Typography-focused layout with generous whitespace, subtle borders, and a restrained color palette.
- 📱 **Fully Responsive:** Fluid grid and flex layouts optimized across mobile, tablet, and desktop screens with zero horizontal overflow.
- 🧭 **Clean Navigation:** Minimal sticky navigation bar with text logo, smooth scrolling anchor links, and an accessible mobile drawer menu.
- 💼 **Project Showcase:** Highlights web development projects with screenshots, descriptive overviews, technology tags, and direct links to live demos and GitHub source code.
- 🛠️ **Skills & Capabilities:** Structured presentation of frontend development skills across markup, styling, scripting, and tooling.
- 📬 **Direct Contact:** Quick links for email correspondence, GitHub profile exploration, and LinkedIn networking.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic document structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, media queries, and responsive typography
- **JavaScript (ES6):** DOM manipulation, scroll navigation, mobile drawer toggle, and dynamic year

## 🚀 Getting Started

### Prerequisites

A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Installation

Clone the repository:

```bash
git clone https://github.com/rafasidhik/Elev-Up.git
cd Elev-Up/portfolio
```

### Run Locally

Open `index.html` in your web browser.
